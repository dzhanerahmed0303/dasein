WestAuto is a web platform that presents a clear and structured catalog of cars, allowing users to browse available vehicles through an organized interface with clean navigation and well‑designed detail pages. The project focuses on clarity, usability, and a smooth viewing experience, making it easy for visitors to explore different models and find the information they need.

The backend is written in TypeScript with Node.js and Express, rendering pages server-side with EJS templates. Car and user data are stored in MongoDB Atlas, with user registration and login secured through bcrypt password hashing and express-session. The front end uses plain JavaScript for the shopping cart, car comparison, adding cars and an interactive Leaflet map on the contact page. The static front end is containerized with Docker (nginx) and deployed on Microsoft Azure behind a Traefik reverse proxy with automatic HTTPS.
