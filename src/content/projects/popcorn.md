Popcorn is a mobile movie discovery application that helps users explore films from different genres and find content that matches their interests. The app focuses on clear information, intuitive navigation, and a modern interface that allows users to browse movies, read reviews, and save their favourite titles in one convenient place.

Built with React Native and Expo, using Expo Router for file-based navigation, and written mainly in JavaScript. The app runs on Android, iOS and the web. Supabase handles authentication, the review database and photo storage, while movie data comes from the OMDb API and SampleAPIs. State is managed with the React Context API and favourites and preferences are stored locally with AsyncStorage. The app also has its own i18n system for multiple languages, dark and light mode, camera support for review photos, and animations built with Reanimated.
